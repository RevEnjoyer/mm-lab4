# ЛР 3.1 — Создание простого фоторедактора

Дисциплина: «Проектирование и программирование мультимедийных приложений».
**Вариант 1** (номер в журнале 20: `20 % 5 + 1 = 1`) — базовый фоторедактор.

| Параметр | Значение |
| --- | --- |
| Элементы | кнопки «Загрузить», «Применить фильтр», «Сохранить»; выпадающий список фильтра |
| Фильтр | «Оттенки серого» (плюс «Оригинал» для отмены) |
| Форматы | JPG, JPEG, PNG, BMP |

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `filters.py` | функция `apply_grayscale()` — логика обработки изображения, отдельно от GUI |
| `photo_editor.py` | главное окно, загрузка/отображение/сохранение |
| `requirements.txt` | зависимости Python |
| `.gitignore` | исключения для Git |
| `INSTRUCTIONS.md` | пошаговая инструкция по выполнению |

## Требования

- Python 3.8+
- PyQt6 6.4+
- opencv-python 4.8+

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python photo_editor.py
```

## Обрабатываемые ошибки

- отмена выбора файла в диалоге загрузки/сохранения;
- файл повреждён или не является изображением (`cv2.imread` вернул `None`);
- попытка применить фильтр без загруженного изображения;
- попытка сохранить без изображения;
- ошибка записи при сохранении (`cv2.imwrite` вернул `False`).
